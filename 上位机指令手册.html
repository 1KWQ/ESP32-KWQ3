添加任务序列 结构电源
已上电		 黄色
  • 只登记，不动机器。把一条任务追加到队列末尾，可以连续下发多条，机器此时不会有任何动作。
  • 一条任务 = 一个样品工位 + 该工位的检测停留时间。
  • 队列最多 10 条，第 11 条回 114；队列只存在内存里，断电或休眠后清空，需重新添加。
  • 执行中也能继续添加，新任务排在队尾，不影响正在跑的那条。
  • 整机回零过程中允许提前编排队列（不抢电机）。
  • 类型 A / B 目前执行流程完全一致，统一填 A 即可。

队列非空		 绿色
  • 把队列从头跑一遍。命令立即回复，真实动作在后台依次执行，所以收到 OK 不代表已经做完。
  • 启动前自动做 9 项检查：结构电源 → 序列空闲 → 队列非空 → 上位机在线 → 舱门关闭 → 样品盘到位 → 电机使能（占位）→ 温度未超限 → 已回零。任一不通过即拒绝并回对应错误码。
  • 每条任务依次做四步：样品盘转到本工位 → 取样位取样 → 检测位停留 T 分钟 → 回收位抛弃。
  • 进度靠阶段事件帧：CHECK BEGIN/OK → SAMPLE BEGIN/DONE → DETECT BEGIN → DWELL BEGIN/END → DETECT DONE → RECYCLE BEGIN/DONE，每帧都带 任务号/总数。出错只发一帧 ERR <原因> <任务号>/<总数>。完整码表见 四、日志与诊断。
  • 全部跑完自动复位：3 号升到 2000、2 号回到 0、4 号样品盘回零；随后清空队列并上报 EVT 300 SEQ ALL DONE。
  • 中途任一步失败或超时：上报一帧 ERR <原因> <任务号>/<总数>（如 ERR 取样动作失败 1/3），再停全部电机，序列回到停止，队列保留便于排查。具体诊断见串口 [任务序列] 步骤失败：… 那一行。
  • 序列运行期间会独占机构，其它 SET EMM * 动作命令一律被拒（查询类不受影响）。

暂停中		 黄色

结束当前任务 运行中
暂停中		 黄色
  • 命令一到就停：立即广播停止全部电机，不等当前动作走完。
  • 随后按回收流程把探头抬回安全高度（3 号先升到安全位，再转回收位、吹扫、落盘）， 不会把探头留在样品或检测位。

  • 若当时还没走到取样位（刚转完盘、还没下降取样），探头本就在安全高度， 自动跳过回收直接进下一条，省一趟空跑。
  • 与 SEQ STOP 的区别：STOP 清空整个队列并做复位；本命令只结束这一条，继续下一条。
  • 暂停中下发会自动解除暂停再执行收尾（语义是"结束"，不是"继续暂停"）。
  • 序列没在跑时下发也回 OK，属于空操作。

急停 任何状态
含未上电		 黄色
  • 就地按死：立即广播停止全部电机 → 清空整个队列 → 序列回到停止状态 → 灯变黄。
  • 不做回收、不做复位，探头停在原地（可能还留在样品里/检测位上）。
  • 同时中止其它复合动作：正在跑的整机回零与系统初始化都会收到中止请求， 在本步结束后退出（否则急停只停了"这一帧"，回零下一步会继续发命令）。
  • ⚠️ 零点失效：执行后 sys_is_homed = false， 此后 SEQ START 会回 104 NO_HOME， 必须先 SET EMM SYSTEM HOME 重新回零。 （理由：急停属于异常终止，现场很可能有人手动盘动过机构。）
  • 任何状态都接受、永不拒绝：序列没在跑、结构电源已断、归位途中——一律回 OK。 这是唯一"无条件可用"的停止命令。
  • 与硬件急停的关系：两者做的是同一套复位（停序列 + 中止回零/初始化 + 清零点）， 区别只在硬件急停会额外切断结构电源，之后必须 SET POWER ON 才能继续； 软件 ESTOP 不切电源。
  • 与 SEQ STOP 的区别：STOP 会先把探头收回安全高度再做复位（要几十秒）； 本命令立刻停、就地停、清零点。
  • 急停后恢复生产的完整步骤：① 人工把探头/样品处理妥当 → ② SET POWER ON（若已断电）→ ③ SET EMM SYSTEM HOME 重新回零 → ④ SEQ ADD … 重新编队 → ⑤ SEQ START。
  • ⚠️ 急停后立刻发 SET EMM SYSTEM HOME 可能回 110 —— 整机回零/初始化任务还在走到检查点，等几秒再发即可。

任务暂停 仅运行中 黄色闪烁
500 ms
  • 立即停机（不等当前动作走完），随后进入归位流程：
  • ① 已取到样 → 先走完整回收流程（样品在回收位被处理掉）； 还没取到样 → 跳过回收。
  • ② 3 号抬到安全高度（5000）→ 2 号转到取样位正上方。
  • ③ 归位完成后才真正进入「暂停」状态，灯变黄色慢闪（500 ms），并发 EVT 380 PAUSE PARKED。
  • ⚠️ 命令应答是「已受理」，不是「已暂停」：OK 立刻返回， 但从 OK 到 EVT 380 之间要回收 + 归位（可能几十秒）。 上位机请以 EVT 380 为准。
  • ⚠️ 暂停会把样品丢掉：回收位是处理样品的地方，不是放回托盘。 所以 SEQ RESUME 后必然重做这条任务，不存在"续跑"。
  • 暂停后探头在取样位正上方、安全高度，可以开门取放样品盘。
  • 重复下发会幂等回 OK（正在归位 / 已暂停都算）；已结束请求处理中时也回 OK 但忽略（结束比暂停更彻底）。
  • 只有在运行中才接受；停止状态下发会回 110。

任务恢复执行 仅暂停中 绿色

获取状态 任何状态 不变
  • 查询系统当前状态，不动任何机构，可随时调用。建议上位机 1 秒轮询一次用于刷新进度。
  • STATUS：0 = 停止，1 = 运行中，2 = 暂停。
  • STEP_PWR：1 = 结构电源已开，0 = 已断电。
  • CUR：当前正在执行第几条，从 0 开始（0 表示第 1 条）。
  • TOTAL：队列里总共有几条任务。
  • HOMING：1 = 已回零，0 = 未回零（未回零时不能 SEQ START）。
 GET STATUS 无 GET STATUS @10 OK @<seq> STATUS=%d STEP_PWR=%d CUR=%d TOTAL=%d HOMING=%d

心跳 任何状态 黄色
断连恢复时
黄灯常亮
  • 上位机定时发（建议 1 秒一次），每收到一次就回 PING @<seq> 并刷新「上位机在线」计时。
  • 超过 30 分钟没收到 PING → 判定上位机断连 → 红灯常亮；此时 SEQ START 会被拒（115），防止无人看管时机器自己跑。
  • 断连后再收到第一个 PING 即恢复，黄灯常亮，可继续操作。
  • 另有指令休眠：连续 30 分钟没有任何指令（含 PING）→ 自动按断电收尾（停序列、清队列、停电机、断结构电源）。
  • 心跳本身不改变序列状态，只影响「允不允许启动」。

整机回零 空闲 不变
  • 启动 17 步整机回零序列（2 号旋转 / 3 号升降 / 4 号样品盘协同），建立全机零点。
  • 流程是 3 号与 2 号交替两轮：3 号回零 → 下 1200 → 2 号回零 → 3 号回零 → 下 1200 → 2 号回零 → 顺 800 → 2 号回零 → 3 号回零 → 下 2500 → 样品盘。因为 2 号旋转会带动 3 号丝杆，所以每轮 2 号动作后都要重标一次 3 号零点。
  • 立即回复后异步执行；结果通过事件帧上报：成功 EVT 360 HOME DONE、失败 ERR 整机回零失败、被主动中止 EVT 362 HOME STOPPED。成功后 HOMING 才变 1。
  • 未回零时 SEQ START 会被拒（104），这是最常见的一次性前置条件。

样品盘单独回零 空闲 不变
  • 4 号样品盘单独回零，流程与整机回零第 17 步一致：
    ① 若接近开关已处于触发状态，先逆时针转出触发区（防零点漂移）；
    ② 顺时针转到接近开关触发 → ③ 关闭接近开关监控 →
    ④ 继续顺时针走 N 脉冲（默认 50，用 SET EMM TRAY ZERO 可改）→
    ⑤ 位置清零（此处即 01 号工位）→ ⑥ 设单圈零点 → ⑦ 读回核对。
  • 同步阻塞（约 1~10 秒），跑完才回复，成败可直接从应答判断。
  • 用于整机回零失败后单独修正样品盘，不必整机重跑。

3 号升降接近开关测试
（试验，2026/10/27）		 空闲 不变

  • 流程：① 若开关已处于触发状态，先下降退出触发区（否则一进来就判"已触发"，等于没测）；
    ② 速度模式向上（DIR=0 RPM=40 ACC=20）→ ③ 开关触发立即发停止 →
    ④ 等停稳（连续两次转速为 0）→ ⑤ 打印触发点读数与本次实际行程。

  • 接近开关接在 GPIO2（板子 Z1 那一路），INPUT_PULLDOWN、高电平触发 —— 与样品盘那一路（GPIO6，低电平触发）极性相反，接线/排查时别搞混。
  • 同步阻塞，最长约 30 秒（满行程 37000 脉冲 @40 RPM ≈ 17.3 秒，故不能沿用通用的 15 秒超时）。
  • ⚠️ 若已下发过 SET EMM LIFT MONITOR ARM=1，请先 ARM=0 再测 —— 否则触发点附近的大电流可能让扎偏保护把 3 号再往上抬一次。

  • 作用：把 01 号工位从"接近开关触发点"顺时针挪开一点，避开触发区边缘的抖动。
  • P=0 表示"触发点即 01 号工位"（等价旧行为）。
  • 运行中也能改（只改内存 + NVS，不动机器）：标定流程进入时只读一次快照，本次不受影响，下次生效。
  • 改了之后建议重新执行一次 SET EMM TRAY HOME 或整机回零，新零点才生效。
 SET EMM TRAY ZERO P=50
  • P：0~3200，只接受整数
  • 带尾随字符（50abc）或超范围（3201）一律回 102

设置序列点位 空闲 不变
  • 设置序列点位，写入 NVS 掉电保存。共 9 个：2 号旋转轴 4 个 + 3 号升降轴 5 个。
  • 2 号出厂默认：SAMPLE=985 / DETECT=2850 / DISC1=320 / DISC2=265。
  • 3 号出厂默认：LIFT_S1=32000 / LIFT_S2=35000 / LIFT_DET=26000 / LIFT_D2=37000 / LIFT_D3=31000。
  • 3 号是丝杆轴，数值越大 = 越往下。
  • 一条命令只设 一个点位；RESET=1 把 9 个全部恢复出厂默认并清除 NVS。
  • 任务序列 / 整机回零运行中也能改单点（含暂停），立即回 OK。生效时机：当前正在执行的那一步不受影响（目标脉冲已下发），从下一步起用新值。
  • 两个例外：回收阶段一次性读 4 个点位再连跑 5 个动作，回收中途改要等下一轮回收；整机回零不读点位，回零中改对本次回零无影响。
  • RESET=1 在复合动作运行中仍拒绝（一次改 9 个，回 110），需先停序列/回零。
  • 序列运行中改完会自动重跑一次点位关系自检，关系不合理只打串口警告、不拒绝（可能正处在"调一半"的中间态）。

  • 只接受整数；带小数（985.5）或尾随字符（985abc）一律回 102

SET EMM POINT 是唯一的例外（2026/10/21 起）：它只改内存变量 + 写 NVS，不产生总线事务、不触发运动， 所以回零/序列运行中也能改单点。但 RESET=1 仍拒绝 —— 一次改 9 个，必须先停。

四日志与诊断默认只发关键消息，需要细节时用一条命令打开

默认只发关键消息。串口与网口（CH9120）接在同一根 UART0 上，日志只有一套，内容是：命令应答 + 阶段事件 + 失败原因。每个动作的 DIR/RPM/ACC/PULSE、到位误差、驱动器标志、点位快照等"流水账"默认不输出。

失败路径永远详细。任何失败 / 超时 / 异常的诊断信息不受开关影响，一定打出来 —— 平时干净，出问题时证据齐全。

掉电不保存。详细日志开关属于临时排查手段，重新上电恢复为"关闭"。

只有命令应答带 @<seq>：OK @600 … / ERR @600 102 的 @600 是你下发命令的序号。所有 EVT 与异常 ERR 都是板子主动上报，不属于任何一条命令，不带 @。

顺序说明：CHECK BEGIN 会先于 OK 到达 —— 前置检查是同步执行的，而 OK 按原有约定只在全部检查通过之后才发（被拒时只回 ERR 1xx）。

每行任务固定 320 → 321 → 330 → 332 → 333 → 331 → 340 → 341：332/333 各出现一次。只有 332 和 333 之间的时间窗才是"该采样的时间"。

出错只发一帧 ERR：格式 ERR <原因> <任务号>/<总数>，随后是详细诊断行（串口）。复位阶段队列已跑完，n/m 会钳到最后一条（如 3/3）。

复位阶段只有 3 帧：350 → 351 → 352，复位完成不另发 DONE，紧接着的 300 就是"整条序列结束"。若 2 号回原点失败（不中止序列），你会看到 350 → EVT 306 ROTARY NOT HOME → 352 → 300，中间缺 351 —— 据此判断是哪一步出的问题。

六相对旧版表格的更正旧表沿用 KWQ1 描述，与本机程序不一致处已按代码改正

  1. 队列上限：旧表「最多 36 条」→ 本机 10 条，超出回 114（旧版是静默丢弃仍回 OK，本机已修正为明确报错）。
  2. SEQ ADD 校验：旧表「S*T>0 且 S*T≤220」→ 本机已取消 S（速度）字段，只校验 工位 1~10 与 T > 0。
  3. T 的单位与小数：本机 T 为分钟且支持小数（旧表未说明），超过 30 分钟按 30 分钟执行。
  4. 心跳超时：旧表「2 s 超时判定断联」→ 本机为 1800 s（30 分钟）；另有 30 分钟无指令的休眠收尾。
  5. SEQ RESUME：旧表参数「无」→ 本机也无参数。 2026/10/20 曾加过可选 MODE=0/1，2026/10/27 已整体移除 （恢复只剩"重做"一种方式）；老上位机带 MODE= 不会报错，参数被忽略。
  6. END ALL 已删除（2026/10/27）：语义整体并入 SEQ STOP。 现在 SEQ STOP = 停机 → 回收 → 清队列 → 复位 → EVT 300； 原来的「就地停 + 清队列」改由新增的 ESTOP 承担。
  7. SEQ PAUSE 已改为「归位式」（2026/10/27）：不再"停在原地"， 而是停机 → 回收（已取样时）→ 探头回到取样位正上方、安全高度 → 发 EVT 380 PAUSE PARKED 后才算真正暂停。OK 只代表已受理。
  8. 启动前检查：旧表提到「水瓶检测」→ 本机实际检查舱门 + 样品盘，无水瓶项（106 未使用）。
  9. 轴数：本机实际使用 3 个 EMM 轴 —— 2 号旋转、3 号升降、4 号样品盘（地址 1 未使用）。旧表「三轴结构电源」的说法是对的，本次核对确认。
  10. 新增一行 SEQ CLEAR：旧表未收录，实际为客户重排任务时的常用命令。
  11. 未收录内容：EMM 底层单一动作命令（66 条）、SET EMM LIFT MONITOR、8 条外设命令按约定不进入本表，需要时查《EMM电机上位机命令手册》与《程序架构与内容总结.md》§5.2。
